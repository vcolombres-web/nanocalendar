# NanoCalendar

Agenda web instalable para organizar entrenamientos, asistentes y cobros.

## Publicación

El sitio está preparado para GitHub Pages y para instalarse como aplicación (PWA) desde un navegador compatible. Los datos de la agenda se guardan localmente en el dispositivo y navegador donde se utiliza. Usá la opción **Copia de seguridad** dentro de la app para exportar o restaurar los datos.

## Archivos

- `index.html`: aplicación.
- `manifest.json`: configuración de instalación.
- `sw.js`: caché básica para uso sin conexión.
- `icon.svg`: ícono de la aplicación.
